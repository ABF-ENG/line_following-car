# 智能车循迹（STM32F407）

车王争霸赛智能小车项目 —— 八路灰度 + 编码器 + 陀螺仪的循迹方案，支持串口实时调参。

[**▶ 演示视频**](docs/demo.mp4)

---

## 硬件

| 部件 | 型号 / 参数 | 备注 |
|---|---|---|
| 主控 | STM32F407VET6，168 MHz | HSE 8 MHz，PLL 168/84/42 |
| 电机驱动 | TB6612 双路 | VM=12V，VCC=3.3V |
| 电机 | MG513P28，GMR 编码器 500 线 | 减速比 28，4 倍频 → 56000 counts/圈 |
| 轮子 | 直径 65 mm | 周长 204.2 mm |
| 灰度传感器 | 八路，CD4051 复用，数字输出 | 最佳离地高度 18 mm |
| 陀螺仪 | MPU6050（I2C1） | 只取 Z 轴 |
| 电池 | 12V | 经 12V→5V 模块给逻辑供电 |

## 软件结构

```
Broad/
├── Gray.c/h          八路灰度驱动（CD4051 轮询，DWT 微秒延时）
├── Motor_base.c/h    电机底层（PWM/方向/编码器）+ PC0 急停
├── Motor_advance.c/h 双轮速度环（前馈 + PI，含堵转保护）
├── Trace.c/h         循迹决策层（PD、丢线计数、盲走、环岛、终点）
├── Mpu6050.c/h       陀螺仪驱动（±500°/s，DLPF 20Hz，零偏校准）
├── Debug_uart.c/h    串口 CSV 输出 + 下行命令解析（非阻塞）
└── PID.c/h           通用 PID 结构（备用）
```

**数据流**

```
Timer6 (20ms 中断)
   └─→ 编码器 Δ计数 → 累计里程 / 瞬时速度
          │
          ├─→ Trace_Tick()        读灰度 + 陀螺仪 → 算出左右轮目标速度
          │        └─→ MotorAdvance_SetTarget()
          │
          └─→ MotorAdvance_Tick() 速度环 PI → PWM 占空比
```

**分层原则**：`Trace` 只决定「该跑多快」，`Motor_advance` 负责「把速度做到」，`Motor_base` 只管「怎么输出 PWM」。

## 上电流程

```
上电
 ├─ 电机 / 灰度 / 速度环 / 陀螺仪初始化
 ├─ Trace_Init()   ← 只初始化，不发车
 └─ 等按键
      ↓ 按 PC2
      ├─ 电机停
      ├─ 陀螺仪零偏校准（1 秒，车必须静止）
      └─ Trace_Start() → 开始循迹
```

跑飞了直接再按一次 PC2 即可重新校准重来，不用断电。

**PC0 是急停**：按下立刻短路刹车并锁存，松手不恢复，必须按 PC2 重新发车。

## 核心算法

### 1. 循迹 PD

八路探头加权重心，X1 最左 = −7，X8 最右 = +7：

```c
e = Σ(weight[i] × mask[i]) / Σ mask[i]        // −7 … +7
e_lpf += 0.6 × (e − e_lpf)                    // 一阶低通，滤量化跳变
steer = KP × e_lpf + KD × (e_lpf − e_lpf_last)
左轮 = BASE + steer      右轮 = BASE − steer
```

低通的作用：20ms 周期下 `Δe` 里量化跳变占比不小，不滤的话 KD 会把它放大成高频抖动。

**退出转向/盲走的第一拍不做微分**（`de` 强制 0），避免 `de = e − 0` 的假跳变。

### 2. 丢线计数（区分直角弯 / 盲走）

不用「丢线瞬间误差大小」判断，而是**按第几次丢线写死**：

| 第几次丢线 | 判定 | 动作 |
|---|---|---|
| 1 ~ 7 | 直角弯 | 朝最后看到的方向打舵找线（±340） |
| 8 | 盲走（断口） | 陀螺仪保持航向 |
| 9+ | 不会再进盲走（`s_blind_done` 已置位） | 打舵找线 |

**三道过滤器**，防止同一个弯被数好几次：

| 过滤器 | 规则 | 可调 |
|---|---|---|
| ① 直道区间 | 第 5 个弯之后那 1 米内没有弯，期间丢线不计数 | `n` |
| ② 6→7 间距 | 第 6 个弯之后必须再走 200mm 才允许数第 7 个 | `o` |
| ③ 全局消抖 | 距上次计数不足 500ms 的丢线不计数 | `q` |

被过滤掉的丢线**仍然按当前计数执行动作**，只是不加次——所以不影响车的行为，只影响计数准确性。

### 3. 盲走（断线通过）

赛道有一段完全没有线，车必须直线冲过去。

```
进盲走：锁定目标航向 = 发车航向 + 180°（赛道绝对方向，而非车头方向）
每 20ms：ye = 目标 − 当前
         steer = −KP_YAW × ye + KD_RATE × 角速度
出盲走：连续 2 拍重新看到线
```

**为什么不用「丢线瞬间的车头方向」**：车进断口时可能正带着修正角，会把歪角锁成目标。

**为什么用角速度做 D 项**：`d(ye)/dt = −角速度`，陀螺仪直接测的就是它，比差分干净得多。默认关闭（`KD_RATE = 0`），车在目标角附近来回摆时再加。

### 4. 盲走前减速

```
第 1~5 个弯        400 mm/s
   ↓ 第 5 个弯之后走 1000mm
降到 300            ← 保持
   ↓ 第 6、7 个弯    300
   ↓ 盲走入口        500（恢复盲走速度）
   ↓ 盲走结束        400
```

目的：最靠近断口的两个直角和断口本身都慢一点，冲出去的风险小很多。

### 5. 环岛

环岛入口是 Y 型岔口，**不会产生全黑**，所以不能用「全黑」判据。

```
盲走出口 → 再走 60cm → 监视 X8（最右侧）上升沿
第 1 次亮 → 忽略
第 2 次亮 → 陀螺仪闭环强制转 30°（220 mm/s）
转完 → 按里程 1000mm 内从 220 渐变回 400
```

### 6. 终点

起终点是同一条粗黑线，规则要求压线后停在停车区。

```
统计「8 路全黑」的上升沿次数
第 4 次压线 → 记录里程 → 直行 200mm → 停车
```

用**次数 + 里程**而不是时间，换速度不用重调。

### 7. 急停（安全）

PC0 按下 → 短路刹车（IN1=IN2=1）+ 锁存。检查放在两处：

- `Motor_EncoderUpdate()`（TIM6 中断里）—— 主循环卡死也能停
- `Motor_SetSpeed()` 入口 —— 防止主循环把输出写回去

## 串口调试

USART2，**115200 8N1**，配合 [SerialPlot](https://hackaday.io/project/5334-serialplot-realtime-plotting-software) 使用。

### 输出格式（20Hz，15 列）

```
#tgtL,spdL,dtyL,tgtR,spdR,dtyR,errx10,steer,mask,yawx10,ratex10,mode,yex10,lev,dist
 400, 395,  27, 400, 398,  28,    12,   45,    24,    35,    -2,    0,    0,  0, 1520
```

| # | 列 | 单位 | 说明 |
|---|---|---|---|
| 1-3 | `tgtL` `spdL` `dtyL` | mm/s, mm/s, % | 左轮：目标 / 实测 / 占空比 |
| 4-6 | `tgtR` `spdR` `dtyR` | 同上 | 右轮 |
| 7 | `errx10` | 0.1 | 循迹误差 ×10（−70…+70） |
| 8 | `steer` | mm/s | 转向差速（循迹 = PD 输出；盲走 = 航向环输出） |
| 9 | `mask` | 位图 | 八路灰度（bit0 = X1，压黑 = 1） |
| 10 | `yawx10` | 0.1° | 陀螺仪航向 ×10 |
| 11 | `ratex10` | 0.1°/s | 角速度 ×10 |
| 12 | `mode` | 枚举 | 见下 |
| 13 | `yex10` | 0.1° | 航向误差 ×10（盲走时应被拉回 0） |
| 14 | `lev` | 次 | 第几次丢线（盲走入口应该是 8） |
| 15 | `dist` | mm | 累计里程 |

`mode`：`0` 循迹、`1` 盲走、`2` 环岛转、`3` 终点冲刺、`4` 未发车、`5` 手动模式

> ×10 的列是为了整数传输 + 保留 0.1 的精度，读的时候除以 10。

### 下行命令（运行时改参数，不用重编译）

格式：**字母 + 数值**，加回车立即生效；不加则停 120ms 后自动生效。支持两位小数。

| 命令 | 参数 | 当前值 | 作用 |
|---|---|---|---|
| `p35` | `KP_TRACE` | 30 | 循迹比例增益 |
| `d18` | `KD_TRACE` | 15 | 循迹微分增益 |
| `b400` | `BASE_MM_S` | 400 | 基础车速 |
| `s340` | `SEARCH_STEER_MM_S` | 340 | 丢线找线差速 |
| `f0.6` | `TRACE_LPF_ALPHA` | 0.6 | 误差低通（1 = 关闭） |
| `l500` | `BLIND_SPEED_MM_S` | 500 | 盲走速度 |
| `y12` | `KP_YAW` | 12 | 盲走航向增益 |
| `v1` | `KD_YAW_RATE` | 0 | 航向速率阻尼 |
| `m300` | `STEER_LIMIT_MM_S` | 300 | 航向修正限幅 |
| `g180` | `BLIND_OFFSET_DEG` | 180 | 盲走目标偏移角 |
| `t220` | `ISLAND_TURN_SPEED` | 220 | 环岛转向速度 |
| `a30` | `ISLAND_TURN_DEG` | 30 | 环岛转向角度 |
| `w1000` | `ISLAND_RAMP_MM` | 1000 | 环岛转向后速度渐变距离 |
| `n1000` | `SLOW_START_MM` | 1000 | 第5弯后多少 mm 减速 |
| `k300` | `SLOW_SPEED` | 300 | 盲走前慢速 |
| `q500` | `LOSS_DEBOUNCE_MS` | 500 | 丢线计数消抖 |
| `o200` | `CORNER6_GAP_MM` | 200 | 第6→7弯最小间距 |
| `300` | — | — | 手动速度模式（Trace 暂停，可测速度阶跃） |
| `0` | — | — | 停车 |
| `c` | — | — | 退出手动，恢复循迹 |

> **断电不保存**：串口改的是 RAM 变量，重启后恢复 `*_DEF` 初值。调好后要写回源码。

## 关键参数

全部集中在 `Broad/Trace.c` 顶部，初值用 `*_DEF` 宏，运行时由 `g_*` 变量承载。

```c
/* 循迹 */
#define BASE_MM_S_DEF          400.0f   // 基础车速
#define KP_TRACE_DEF            30.0f   // 比例增益
#define KD_TRACE_DEF            15.0f   // 微分增益（未除以周期，等效阻尼 = KD × 周期）
#define SEARCH_STEER_MM_S_DEF  340.0f   // 丢线找线差速
#define TRACE_LPF_ALPHA_DEF      0.6f   // 误差低通，1 = 关闭

/* 丢线计数 */
#define CORNER_COUNT             7u     // 第几个弯之后算盲走
#define LOSS_DEBOUNCE_MS_DEF   500u     // 全局丢线消抖
#define CORNER6_GAP_MM_DEF     200.0f   // 第6→7弯最小间距

/* 盲走前减速 */
#define SLOW_AFTER_CORNER        5u
#define SLOW_START_MM_DEF     1000.0f
#define SLOW_SPEED_MM_S_DEF    300.0f

/* 盲走 */
#define BLIND_SPEED_MM_S_DEF   500.0f
#define BLIND_OFFSET_DEG_DEF   180.0f
#define KP_YAW_DEF              12.0f
#define KD_YAW_RATE_DEF          0.0f

/* 环岛 */
#define ISLAND_WATCH_MM        600.0f
#define ISLAND_EDGE_N            2u
#define ISLAND_TURN_DEG_DEF     30.0f
#define ISLAND_TURN_SPEED_DEF  220.0f
#define ISLAND_RAMP_MM_DEF    1000.0f

/* 终点 */
#define FINISH_CROSS_N           4u
#define FINISH_RUN_MM          200.0f
#define FINISH_SPEED_MM_S      350.0f
```

> **调参注意**：
> - `BASE` 改了，`KP` 要按同比例改
> - 控制周期改了（20ms ↔ 10ms），`KD` 要跟着变（等效阻尼 ∝ KD × 周期），所有按拍计的超时也要跟着改

1. 用 **Keil MDK 5** 打开 `MDK-ARM/f4.uvprojx`

## 已知限制

| 限制 | 说明 |
|---|---|
| 20ms 采样 | 400mm/s 时每拍走 8mm，再提速建议把 TIM6 改成 10ms（PSC 167→83，`CTRL_PERIOD_MS` 同步改，`KD` 减半） |
| 16 位右编码器 | TIM3 每 239mm 溢出一圈，必须靠 int16 差分累加 |
| 陀螺仪无磁力计 | yaw 无法自校正，零偏残差会让静止时缓慢漂移；发车时按 PC2 会重新校准归零 |
| 航向控制不能纠横向偏移 | 盲走只能保持方向，进断口偏了就会一直偏下去；只能调 `BLIND_OFFSET_DEG` 补偿 |
| 丢线计数依赖赛道固定 | 弯道数量、间距变了要同步改 `CORNER_COUNT` / `o` / `n` |
