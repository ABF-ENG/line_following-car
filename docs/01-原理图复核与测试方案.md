## 0. 一句话结论

**电路拓扑是通的、功能分区清楚，可以直接打样验证；但有 2 处"插上就可能烧"的排针一致性必须先量，3 处器件安全问题建议改版，另外缺了比赛规则要求的"声控发车"。**

按严重程度排：

| 级别 | 问题 | 后果 | 处理 |
|---|---|---|---|
| **P0** | 右侧 22P 排母第 3 行内侧接 GND，而核心板 J3 的 pin6 是 **VREF+** | 若核心板 VREF+ 经 0Ω 接 3V3 → 3.3V 对地短路，整板不启动 | 上电前必测（见 §3.2） |
| **P0** | 右侧排母第 5 行起，**内侧列的引脚标注整体错位一行** | OLED SDA、编码器 A/B、按键全部落到别的脚上，调一天也调不出来 | 按 §3.1 用万用表重排 |
| **P1** | 编码器 5V 供电，A/B 直接进 PA0/PA6/PA7（**非 5V 容忍**） | 长期打穿 IO，偶发丢脉冲 | 连接器 VCC 改 3V3（改版） |
| **P1** | 电机驱动 STBY 硬接 5V（VCC=3.3V），且无软件急停 | 逻辑电平不统一；失控时只能拔电 | STBY 改接 GPIO |
| **P1** | 12V 入口无防反接；5A PPTC 对 TB6612 偏大 | 接反 → TVS 先死；堵转 → 驱动先死 | 加 P-MOS 防反接、保险改 3A |
| **P1** | 无 5V 大电容 / 无 100nF 去耦 / 电机地与信号地未分开 | PWM 一开就复位、ADC 乱跳 | 改版补电容 + 单点接地 |
| **P2** | **没有声音检测**，规则要求"声控发车" | 不符合竞赛规定 | 加声音传感器模块（1 个 GPIO） |
| **P2** | 无电源灯 / 无状态灯 / 无测试点 | 调试全靠猜 | 补 LED + 测试点 |
| **P2** | `.ioc` 里 HSE=25MHz，核心板实际是 **8MHz** 晶振 | PLL 配 168M 全错、波特率全错 | 改 HSE=8MHz |

## 1. 板子做了什么（我读图的理解）

```
DC-005 12V ──SW1──F1(5A PPTC)──+12V──┬── TVS1(16V)
                                      ├── 电机模块 VM + 100µF
                                      └── 12V→5V 模块 ── 5V ──┬── SW2 ── 5V_MSP ── 核心板 5V ── AMS1117 ── 3V3
                                                              ├── 编码器 ×2
                                                              ├── 灰度模块
                                                              └── 电机模块 STBY
3V3（核心板 LDO 回送）── OLED / MPU6050 / 蓝牙 / 电机模块 VCC
```

- 4 个 22P 排母（88 pin）套在 STM32F407VET6 核心板上，扩展板当"底板"用；
- 15 脚电机驱动模块座（TB6612 类：VM/VCC/AO1/AO2/BO1/BO2/PWMA/AIN1/AIN2/PWMB/BIN1/BIN2/STBY/GND×2）；
- 2 个 XH2.54-6P 电机+编码器口、1 个 XH2.54-6P 灰度口；
- OLED(I2C2)、MPU6050(I2C1)、蓝牙(USART1)、调试串口(USART2)、3 个按键。

### 1.1 引脚分配（这就是固件要用的表）

| 功能 | 网络 | MCU 脚 | 复用/模式 |
|---|---|---|---|
| 左电机 PWM | PWMA | **PE9** | TIM1_CH1 (AF1) |
| 左电机方向 | AIN1 / AIN2 | **PE2 / PE3** | GPIO 推挽 |
| 右电机 PWM | PWMB | **PE11** | TIM1_CH2 (AF1) |
| 右电机方向 | BIN1 / BIN2 | **PE4 / PE5** | GPIO 推挽 |
| 左编码器 A/B | — | **PA0 / PB3** | TIM2_CH1 / CH2 编码器模式 |
| 右编码器 A/B | — | **PA6 / PA7** | TIM3_CH1 / CH2 编码器模式 |
| 灰度地址 | AD0/AD1/AD2 | **PD0 / PD1 / PD2** | GPIO 输出 |
| 灰度输出 | ADC_read | **PD3** | GPIO 输入（数字量！） |
| OLED | SCL/SDA | **PB10 / PB11** | I2C2 |
| MPU6050 | SCL/SDA/INT | **PB6 / PB7 / PD7** | I2C1 |
| 蓝牙 | TX/RX/STATE | **PA10 / PA9 / PA8** | USART1（115200） |
| 调试串口 | TX/RX | **PA2 / PA3** | USART2 |
| 按键 0/1/2 | — | **PC0 / PC1 / PC2** | 输入上拉，按下=0 |

> 注：`ADC_read` 这个名字有误导——八路灰度模块手册写明 **OUT 是数字量**（CD4051 选通后输出高低电平），不是模拟量，所以 PD3 当 GPIO 用是对的，不需要 ADC。建议改版时把网络名改成 `TRACK_OUT`。

## 2. 逐模块复核

### 2.1 供电链路 ✅ 拓扑正确，4 处要补

路径：`DC座 → SW1 → F1 → +12V → {TVS1, 电机VM, 12V转5V} → 5V → SW2 → 5V_MSP → 核心板`

- ✅ 开关在保险丝前、TVS 在保险丝后，这个顺序是对的（TVS 泄放电流会走保险丝）。
- ⚠️ **无防反接**：DC 座接反时，TVS1 正向导通形成死短路，5A PPTC 要几秒才动作，TVS 大概率先炸。→ 加一只 P-MOS（AO3401 类）或串 SS54。
- ⚠️ **保险丝 5A 偏大**：TB6612 每通道连续 1.2A、峰值 3.2A，两路堵转能到 5A 以上。PPTC 是"慢断"，堵转时先坏的往往是驱动。→ 改 3A，或电机单独 3A + 逻辑 1A。
- ⚠️ **5V 没有大电容**：只有模块自带的。两路电机启动瞬间 5V 会被拉低，核心板 LDO 跟着掉，MCU 复位。→ 5V 加 220µF 电解 + 100nF。
- ⚠️ **整板没有一颗 100nF**：3V3 全从核心板经排针过来，OLED/MPU/电机模块 VCC 处应各加 100nF。
- ⚠️ **地**：电机电流（峰值几安）和 MCU 共地，且是排针细线回流。→ 电机 GND 单独走粗线到电源入口，单点接地；电机两端并 100nF（或者用带电容的电机线）。
- 💡 12V 电池若是 3S 锂电（满电 12.6V），已经接近 TB6612 的 VM 上限 13.5V，电机换向尖峰很容易超。TVS1 是 16V 型号（钳位 ~26V），**保护不了 VM**。→ VM 处再加一只 15V TVS + 100nF。

### 2.2 电机驱动（15 脚 TB6612 类模块）

- VM=12V ✅、VCC=3V3 ✅（TB6612 逻辑 2.7–5.5V 都行）、AO/BO 到 XH2.54 ✅（3A/针够用）。
- ⚠️ **STBY 硬接 5V**：TB6612 的输入绝对最大 5.5V，5V 不会立刻坏，但 (a) 和 VCC=3.3V 不统一；(b) 没有软件急停——比赛时程序跑飞只能拔电。→ **STBY 改接一个空闲 GPIO**（比如 PD4），上电默认拉低，程序里再拉高。
- 💡 建议加"刹车"策略：AIN1=AIN2=1 是短路刹车，=0 是滑行。循迹过弯用刹车比滑行稳。

### 2.3 编码器接口 ⚠️ 选脚很好，电平有风险

XH2.54-6P：`1=AO1(M+) 2=GND 3=PB3 4=PA0 5=5V 6=AO2(M-)`（左）；右路 `BO1/PA7/PA6/BO2`。

- ✅ TIM2(PA0/PB3) + TIM3(PA6/PA7) 是标准硬件编码器口，四倍频，选脚非常合适。
- ✅ PB3 是 JTDO，**CubeMX 里 Debug 必须选 Serial Wire**（你已经选了），否则 PB3 当不了 TIM2_CH2。
- ❌ **PA0/PA6/PA7 是模拟脚（TTa），不是 5V 容忍**。编码器若 5V 供电、输出推挽 5V，会通过 IO 的 ESD 二极管往 3.3V 灌电流，轻则丢脉冲重则打穿。→ **改版把连接器 5V 改 3V3**（绝大多数霍尔编码器 3.3V 都能工作）。
- 💡 每路加 RC 滤波（100Ω + 100nF 到地），编码器线用双绞或屏蔽线，否则电机 PWM 串扰会让计数乱跳。
- 💡 核心板上 **K2 按键接在 PA0（WK_UP）**、**PA1 上有用户 LED**。PA0 拿来当左编码器 A 相后，按核心板 K2 会干扰计数，比赛时别按；PA1 的 LED 可以白嫖当心跳灯。

### 2.4 灰度/循迹 ⚠️ 两个电平隐患

XH2.54-6P：`1=5V 2=AD2 3=AD1 4=AD0 5=OUT 6=GND` → `PD0/PD1/PD2` 选址、`PD3` 读值。

- ✅ 4 根线读 8 路，控制周期内完全够（每次切换留 5–10µs 建立）。
- ⚠️ **模块要 5V、OUT 也是 5V 电平**：PD3 在 F407 上属于 FT（5V 容忍）脚，理论上能接，但建议按 datasheet Table 7 再核一眼。
- ⚠️ **AD0–AD2 用 3.3V 去驱动 5V 供电的 CD4051**：VDD=5V 时 VIH≥3.5V，3.3V 属于"能用但不在规格内"，可能出现通道选错（表现：某一两位永远读同一路）。
- ✅ **最省事的解法**：把灰度口的 5V 改接 **3V3**（手册写 5V，但 3.3V 下 LED 稍暗、功能正常）。这样 OUT 是 3.3V、地址也是 3.3V，全链路统一，两个隐患一起消掉。若坚持 5V，则 OUT 串 1k + BAT54 钳位到 3V3，地址线加 74LVC1T45 电平转换（或 4051 单独供 3.3V）。
- 💡 比赛要素（S 弯、伪直角、圆环、十字、全黑终点）建议用"8 路阈值 + 状态机"，阈值做成可调（按键或蓝牙改参数存 Flash），现场换场地不用重新烧程序。

### 2.5 MPU6050 ✅ 基本没问题

`PM2.54-1×8：8=3V3 7=GND 6=SCL(PB6) 5=SDA(PB7) 4/3/2=NC 1=INT(PD7)`

- ✅ 独立 I2C1，和 OLED 的 I2C2 分开，好。
- ⚠️ **AD0 悬空**：地址靠内部下拉，一般 0x68，但不同批次模块不一定。→ 改版把 AD0 接地，地址固定。
- 💡 装在电机旁边噪声大：I2C 走线远离电机线，100kHz 慢速 + 中值滤波；陀螺仪零偏要上电静止校准。

### 2.6 OLED / 蓝牙 / 串口 / 按键 ✅

- **OLED** 4P：3V3/GND/PB10/PB11（I2C2）。常见 SSD1306，地址 0x3C（少数 0x3D）。模块自带 4.7k 上拉，别重复并太多。
- **蓝牙** 6P：`2=3V3 3=GND 4=TX→PA10 5=RX→PA9 6=STATE→PA8`。✅ TX/RX 交叉正确（模块 TX 接 MCU RX）。
  - ⚠️ HC-05/06 标称 3.6–6V 供电，3.3V 能跑但发射功率略低；要距离就把 VCC 接 5V（它的 IO 是 3.3V 电平，RX 串 1k 更稳）。
  - 💡 比赛正式跑要关蓝牙（规则不允许遥控），只用于调参。
- **串口引出** U19：`1=3V3 2=GND 3=TX(PA2) 4=RX(PA3)`。
  - ⚠️ 1 脚是 3V3 **输出**，接 USB-TTL 时**千万别接它的 VCC**（会回灌 3.3V，甚至和核心板 LDO 打架）。→ 改版把这脚改成 NC 或 5V 更安全。
- **按键** PC0/PC1/PC2 → GND，无外部上拉 → 用内部上拉，按下为低。软件 20ms 消抖即可。

### 2.7 对照比赛规则，缺的东西

规则原文：「**声控发车，自动停车**，并寻找到正确的轨迹」。

- ❌ **没有声音检测**。板上没有麦克风/声音传感器。→ 必须加一个"声音传感器模块"（LM393 比较器型，数字输出），VCC 3.3V，OUT 接一个空闲 GPIO（推荐 **PD4**，右排第 8 行外侧 PE14 那个位置旁边的空脚不行的话就用 PC4/PC5 或 PD5/PD6，注意别和已用脚冲突）。
  - 软件：上电后等 OUT 出现一次有效脉冲（可要求持续 >30ms）再起步，避免观众咳嗽误触发。
- ⚠️ **自动停车**：终点全黑 → 8 路全 1 且持续 >50ms 即判定到终点，停车；同时加"最长运行时间"保护（比如 30s 强制停）。
- 💡 **状态指示**：建议加 1 个 3V3 电源灯（串 1k）+ 1 个用户灯；目前整板没有灯，调试时根本不知道程序跑没跑。
- 💡 **测试点**：12V / 5V / 3V3 / GND 各留一个焊盘或测试环，示波器好钩。
- ❓ **安装孔**：图上没看到 M3 固定孔，装车时注意。

## 3. 上电前必须先解决的两件事

### 3.1 排针行序（P0，最重要）

你的板子是"底板套核心板"，**核心板每个排针的物理位置必须和你的网络一一对上**。我把你图纸上的 4 个 22P 排母，和核心板资料逐行比了一遍：

**左侧排母（J2，2×22）—— ✅ 基本全对**

| 行 | 你的图纸（外/内） | 核心板 J2（奇/偶） | 结论 |
|---|---|---|---|
| 1 | 5V / 5V | 5V(1) / 5V(2) | ✅ |
| 2 | 3V3 / 3V3 | 3V3(3) / 3V3(4) | ✅ |
| 3 | GND / GND | GND(5) / GND(6) | ✅ |
| 4–10 | PD8 PB15 / PD10 PD9 / … / PA8 PC9 | 一致 | ✅ |
| **11** | **PA9 / PA10** | **PA10(21) / PA9(22)** | ⚠️ 内外**互换**了 |
| 12–22 | PA12 PA11 … PE1 PE0 | 一致 | ✅ |

第 11 行：如果核心板确实是 `PA10` 在外、`PA9` 在内，那你的蓝牙 TX/RX 就是反的。**但这只需在 CubeMX 里把 USART1 的 TX/RX 对调即可**（或者飞两根线），不影响比赛。

**右侧排母（J3，2×22）—— ❌ 内侧列从第 5 行起整体错位一行**

核心板 J3 的引脚表（从 `1779674529718247.pdf` 读出，pin1–44）：

```
1 3V3    2 3V3     3 GND     4 GND     5 GND     6 VREF+
7 VDDA   8 PB13    9 PB14   10 PB11   11 PB12   12 PE15
13 PB10  14 PE13   15 PE14  16 PE11   17 PE12   18 PE9
19 PE10  20 PE7    21 PE8   22 PB0    23 PB1    24 PC4
25 PC5   26 PA6    27 PA7   28 PA4    29 PA5    30 PA2
31 PA3   32 PA0    33 PA1   34 PC2    35 PC3    36 PC0
37 PC1   38 PE6    39 PC13  40 PE4    41 PE5    42 PE2
43 PE3   44 —
```

按这个表，**正确的行序**应该是：

| 行 | 外（奇） | 内（偶） |
|---|---|---|
| 1 | 3V3 | 3V3 |
| 2 | GND | GND |
| 3 | GND | **VREF+** |
| 4 | VDDA | **PB13** |
| 5 | PB14 | **PB11** |
| 6 | PB12 | **PE15** |
| 7 | PB10 | **PE13** |
| 8 | PE14 | **PE11** |
| 9 | PE12 | **PE9** |
| 10 | PE10 | **PE7** |
| 11 | PE8 | **PB0** |
| 12 | PB1 | **PC4** |
| 13 | PC5 | **PA6** |
| 14 | PA7 | **PA4** |
| 15 | PA5 | **PA2** |
| 16 | PA3 | **PA0** |
| 17 | PA1 | **PC2** |
| 18 | PC3 | **PC0** |
| 19 | PC1 | **PE6** |
| 20 | PC13 | **PE4** |
| 21 | PE5 | **PE2** |
| 22 | PE3 | — |

而你图上是：

| 行 | 外 | 内 | 问题 |
|---|---|---|---|
| 1–4 | 3V3 / GND / GND / VDDA | 3V3 / GND / **GND** / **UREF+** | 第 3 行内侧：你把 pin6 接了 **GND**，核心板是 **VREF+** |
| 5 | PB14 | **PB13** | 应为 PB11，你的 PB13 是 pin8（上一行） |
| 6 | PB12 | **PB11** | 应为 PE15 → **OLED 的 SDA 会落错脚** |
| 7 | PB10 | **PE15** | 应为 PE13 |
| 8 | PE14 | **PE13** | 应为 PE11 |
| … | … | 每行都往前串一位 | 一直错到第 22 行 |
| 14 | PA7 | **PA6** | 应为 PA4 → **右编码器 B 相落错脚** |
| 17 | PA1 | **PA0** | 应为 PC2 → **左编码器 A 相（PA0）落错脚** |
| 18/19 | PC3 / PC1 | **PC2 / PC0** | 应为 PC0 / PE6 → **按键落错脚** |

**结论：外侧列全对，内侧列（偶数脚）从第 5 行开始整体错位一行。** 这会让 OLED、右编码器 B 相、左编码器 A 相、两个按键全部接到别的引脚上——现象就是"代码明明对，就是没反应"，而且极难查。

**怎么确认（10 分钟，不用上电）：**

1. 只拿核心板，不插你的板子，用万用表 **通断档**：
   - 红表笔点核心板 MCU 的某个可识别焊盘不现实，改用"**已知电源脚**"反推：
   - 先量 J3：`pin1` 对 `pin2`（应都通 3V3）、`pin5` 对 `pin3/4`（GND）、**`pin6` 对 `pin5`（如果不通，说明 pin6 是 VREF+，不是 GND）**、`pin6` 对 `pin1`（如果通，说明 VREF+ 直接接 3V3）。
2. 再量"靠丝印"：核心板底面丝印印着每个脚的名字（页面 2 的图就是丝印）。**以丝印为准，把 44 个脚的名字抄一遍**，和上表对照。
3. 最稳的办法：核心板单独插 USB 供电，**用万用表直流档量 J3 每个脚对 GND 的电压**：
   - 3.3V 的脚 = 3V3 或 VREF+；
   - 0V 的脚 = GND（注意区分"真的是 GND"和"悬空"——悬空脚量出来是浮动的，可以再用通断档对 GND 确认）。
   - 这一步能 100% 确定 pin6 到底是 GND 还是 VREF+。

> **如果你已经打样了**：内侧列错位只能靠飞线救（把排母对应针脚用细线改接），或者干脆不插满、只插外侧列 + 手动飞几根关键信号。**改版必须先把这张表定死，再画 PCB。**

### 3.2 VREF+ 被接地（P0）

上表第 3 行：你的 pin6 = **GND**，核心板 pin6 = **VREF+**。

- 如果核心板的 VREF+ 是"经 0Ω/磁珠接 3V3 + 104 电容"（这类核心板大多如此），你把 pin6 接地 = **3.3V 直接对地短路**。上电现象：核心板 LDO 发烫、3V3 掉到 0.x V、ST-Link 连不上，甚至烧 LDO。
- 如果 VREF+ 只接了电容没接 3V3，那只是 ADC 基准没了（MCU 能跑，ADC 读数全 0），不烧板。

**先量**：核心板单独上电，量 J3 pin6 对 GND 的电压。
- ≈3.3V → **你的板子千万不能插**，必须把 pin6 的网络从 GND 改成 NC（割断那一根）。
- ≈0V 或悬空 → 可以用，但建议还是改成 NC（VREF+ 留给核心板自己）。

## 4. 板级测试流程（照着做，一步一停）

> 工具：可调直流电源（带限流）、万用表、示波器（可选）、ST-Link、USB-TTL。
> **原则：先不加电测通断，再加电测电压，最后才插核心板。**

### Phase 0 — 静态检查（不上电，10 min）

| # | 操作 | 期望 | 异常处理 |
|---|---|---|---|
| 0.1 | 目视：排母/座子有无连锡、虚焊、歪针；XH2.54 座子方向 | 无连锡 | 补焊/吸锡 |
| 0.2 | 万用表通断：`+12V ↔ GND` | 不响（>10kΩ） | 有短路先查 TVS/电容 |
| 0.3 | `5V ↔ GND`、`3V3 ↔ GND` | 不响（>1kΩ） | 查模块座子是否插反 |
| 0.4 | `F1` 两端通断 | 通（<1Ω） | 保险丝已断 |
| 0.5 | 对照网表逐点通断（§5 表） | 全通 | 找出 PCB/原理图不一致 |
| 0.6 | 排母 pin1 方向与核心板 pin1 对齐（丝印方焊盘） | 一致 | **插反必烧** |

### Phase 1 — 空载上电（不插核心板，5 min）

| # | 操作 | 期望 | 异常处理 |
|---|---|---|---|
| 1.1 | 电源设 **12.0V / 限流 200mA**，接 DC 座，SW1 断开 | 电流 ≈0 | 有电流 → 开关/保险丝接错 |
| 1.2 | SW1 合上 | 电流 10–40mA（只有 12V→5V 模块空载） | >100mA 立即断电查 |
| 1.3 | 量 `+12V` 对 GND | 11.9–12.1V | 低 → 保险丝/开关压降大 |
| 1.4 | 量 `5V` 对 GND | **4.90–5.10V** | 偏差大 → 模块坏或接错 |
| 1.5 | 示波器看 5V 纹波（AC 档，20MHz 带宽限制） | <50mVpp | 大 → 缺电容，先并 100µF |
| 1.6 | 量 `3V3` | ≈0V（没插核心板，正常） | 有电压 → 说明有地方倒灌，查 |
| 1.7 | SW2 拨到 OFF/ON 各一次 | 5V_MSP 通/断 | — |

> 此时 **不要** 插电机、不要插灰度模块。

### Phase 2 — 插核心板（关键一步）

| # | 操作 | 期望 | 异常处理 |
|---|---|---|---|
| 2.1 | **断电**，插核心板（注意 pin1、注意别错位一排） | 插到底、平整 | 歪针会顶弯排母 |
| 2.2 | 电源限流调到 **300mA**，上电，SW2=OFF | 电流 20–60mA | 突增 → 立即断电，回 §3.2 查 pin6 |
| 2.3 | 量 `3V3`（J3 pin1 或 OLED VCC） | **3.25–3.35V** | 0V/偏低 → 核心板 LDO 保护或短路 |
| 2.4 | 量核心板 LDO、TVS、驱动模块温度 | 常温（不烫手） | 发烫立即断电 |
| 2.5 | SW2=ON，再看 3V3/电流 | 不变或略增 | — |
| 2.6 | 按一下核心板复位键 | 电流有轻微跳动 | — |

### Phase 3 — MCU 连通（10 min）

| # | 操作 | 期望 | 异常处理 |
|---|---|---|---|
| 3.1 | ST-Link 接 SWD（SWDIO/SWCLK/GND/3V3），Keil 里能识别 | 读到 **0x413**（F407VE，1MB Flash） | 连不上 → 查 BOOT0=0、SWD 线序、核心板供电 |
| 3.2 | 下载一个 LED 闪灯程序 | 核心板 PA1 的 LED 闪 | 不闪 → 晶振/时钟配置 |
| 3.3 | 用 `board_test.c` 的 VDD 测量打印 | 读到 3250–3350mV | 偏差大 → VDDA/VREF+ 有问题（正好验证 §3.2） |
| 3.4 | 串口（USART2，115200）打印心跳 | 每 500ms 一行 | 乱码 → HSE 频率设错（见 §6.1） |

### Phase 4 — 外设逐个点亮（按这个顺序，别跳）

| 顺序 | 模块 | 测试方法 | 通过判据 |
|---|---|---|---|
| 1 | **按键** | 按 PC0/PC1/PC2，看串口打印 | 按下=0，松开=1，无抖动 |
| 2 | **OLED** | I2C2 扫描 | 扫到 **0x3C**（或 0x3D），能显示字符 |
| 3 | **MPU6050** | I2C1 扫描 + 读 WHO_AM_I(0x75) | 扫到 **0x68**，WHO_AM_I=**0x68**；静止时陀螺仪 ≈0 |
| 4 | **调试串口** | USART2 回环（TX 接 RX） | 发什么回什么 |
| 5 | **蓝牙** | USART1，手机连 HC-05 发字符 | 手机发 → 串口打印；串口发 → 手机收 |
| 6 | **灰度** | 白纸/黑胶带下扫 8 路 | 白底全 0（或全 1），黑线对应位翻转；8 路都能单独变化 |
| 7 | **编码器** | 手转轮子，看 TIM2/TIM3 计数 | 正转增、反转减，计数连续不跳变 |
| 8 | **电机** | **轮子架空**，先 30% 占空比正转/反转/停 | AO1/AO2 电压 ±(占空比×12V)；转向正确；停得下来 |
| 9 | **联调** | 装车，地上贴黑线，低速循迹 | 能跟线、能过十字、能停 |

> **电机测试务必架空轮子**，第一次上电不要落地，防止飞车。

### Phase 5 — 整车联调（赛前）

1. 低速（30%）跑通直线 → 再加 S 弯 → 圆环 → 十字 → 全黑终点；
2. 记录每段的 PWM/转向参数，做成可调；
3. **声控发车**联调：拍手/哨声 → 30ms 内起步；误触发率要压到 0；
4. 断电重启 20 次，确认每次都能正常发车（电源/复位可靠性）；
5. 电池从满电放到 11V，确认低压下不误动作（TB6612 掉压、LDO 掉压）。

## 6. 软件侧要注意的 5 件事

### 6.1 HSE 是 8MHz，不是 25MHz

`f4.ioc` 里 `RCC.HSE_VALUE=25000000`，但核心板原理图 OSC_IN/OSC_OUT（pin12/13）上挂的是 **Y2 = 8M**（32.768K 是 RTC 的 Y1）。→ CubeMX 里把 HSE 改成 8MHz，再配 PLL（8M/8×336/2 = 168MHz 标准配置），否则串口全是乱码、延时全错。

### 6.2 现在的 .ioc 是空的

只有 SWD + SysTick，所有外设都没配。按 §1.1 的表配：

| 外设 | 配置 |
|---|---|
| SYS | Debug = **Serial Wire**（释放 PB3/PB4/PA15） |
| RCC | HSE = 晶振 8MHz，PLL → 168MHz |
| TIM1 | CH1=PE9, CH2=PE11, PWM Generation, 20kHz |
| TIM2 | Encoder Mode TI1&TI2, PA0/PB3, 32 位 |
| TIM3 | Encoder Mode TI1&TI2, PA6/PA7（16 位，软件扩展） |
| I2C1 | PB6/PB7, 100kHz（MPU） |
| I2C2 | PB10/PB11, 100kHz（OLED） |
| USART1 | PA9/PA10, 115200（蓝牙） |
| USART2 | PA2/PA3, 115200（调试） |
| GPIO | PE2–PE5 输出；PD0–PD2 输出；PD3/PD7/PA8 输入；PC0–PC2 输入上拉 |

### 6.3 电机 PWM 用 20kHz

低于 20kHz 电机有啸叫、电流纹波大；高于 20kHz TB6612 开关损耗上来。20kHz、100 级分辨率（TIM1 时钟 168MHz，PSC=0, ARR=8399 或 PSC=84-1, ARR=99）。

### 6.4 编码器计数要软件扩展

TIM2 是 32 位（够用），**TIM3 只有 16 位**，跑 2.4m 赛道会溢出。做法：1ms 定时器里读 TIM3->CNT，和上次值求差（按 int16 处理），累加到 int32。

### 6.5 上电顺序与失效保护

- 上电先把 STBY 拉低、PWM=0、方向脚全 0，再初始化，最后才允许电机使能；
- 主循环加看门狗（IWDG，2s），跑飞自动复位；
- 灰度全黑 + 超时 → 停车。

## 7. 改版（V1.1）清单

**P0（不改不能上电）**
1. 排母行序按 §3.1 重画，pin1 丝印标清楚；右侧 pin6 改 NC。
2. 排母丝印在 PCB 上标出每一行的信号名（正面丝印，插错能一眼看出来）。

**P1（可靠性）**
3. 编码器/灰度连接器 VCC 改 **3V3**（或加电平转换）。
4. STBY 改接 PD4（GPIO），留软件急停；再加一个"硬件急停"按键串在 STBY 上更好。
5. 12V 入口加 P-MOS 防反接；保险丝 5A→3A；VM 加 15V TVS + 100nF。
6. 5V 加 220µF + 100nF；3V3 每处 100nF；电机地与信号地单点连接。
7. I2C 各串 22Ω；编码器各加 100Ω+100nF。

**P2（好用/合规）**
8. 加声音传感器接口（5V/3V3、GND、OUT→PD4 或 PC4）。
9. 加电源 LED、用户 LED（PD5）、复位按键、4 个测试点。
10. U19 的 1 脚改 NC 或 5V（防回灌）。
11. 加 M3 安装孔 ×4。

## 8. 固件自检程序怎么用

文件：`board_test.c` / `board_test.h`（同目录）。

1. 把两个文件加进 MDK 工程（`Application/User/Core` 分组）；
2. `main.c` 里 `#include "board_test.h"`，在 `while(1)` 之前调用 `BoardTest_Run();`（它不会返回）；
3. 用 **USART2（PA2/PA3，115200 8N1）** 接 USB-TTL，串口助手打开；
4. 按提示输入命令字母。

| 键 | 功能 | 通过判据 |
|---|---|---|
| `v` | 读内部 VREFINT 反算 VDD | 3250–3350mV |
| `i` | 扫 I2C1 / I2C2 | 0x68（MPU）、0x3C（OLED） |
| `m` | 读 MPU WHO_AM_I + 加速度 | WHO_AM_I=0x68 |
| `b` | 按键状态 | 按下=0 |
| `t` | 灰度 8 路循环打印 | 黑白能区分 |
| `e` | 编码器计数 5s | 手转有变化 |
| `p` | 电机 PWM 斜坡（**轮子架空**） | 正反转、能停 |
| `s` | 电机单步：正/反/刹/停 | 听声音、看转向 |
| `h` | 帮助 | — |

> 这个程序是**独立初始化**的（自己开时钟、自己配 GPIO/外设），不依赖 CubeMX 生成代码，所以现在这个空工程也能直接编译跑。

## 9. 一句话给队友

> 板子能打，但**插核心板之前，先用万用表把右侧排母的内侧列量一遍**——外侧列没问题，内侧列从第 5 行开始错位一格，OLED、编码器、按键全在那一列。这一件事不做，后面所有调试都是白费。
